# The Average Bloatware Linux Distro

Linux users will all rejoice today. I have made a Linux distro so free of bloat, that it can't do anything. It only has 3 commands: `sudo apt update`, `sudo apt install`, and `sudo apt upgrade`. You can't even see your text until you install the things that make it visible. Very usable, clearly.

## Bare Metal Warning
This monstrosity of a distro has no bootloader or password for it. If you're going to install it for whatever reason, be warned that it'll make your other operating system unbootable. Fixing that in a blank void where you can't see your text will be an absolute nightmare.

## Virtual Machine Warning
This distro is exactly how it sounds. It has nothing in it. I would not recommend booting this in a VM either because it is REALLY just that boring. It is a waste of time unless your goal is to turn it into a usable operating system for some dare or something. Please believe me, it is just as useless and boring as I'm making it out to be.
